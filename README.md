# Commit Style

Пишет сообщения коммитов в едином стиле команды: Conventional Commits, текст на русском.

```
fix(auth): отзывал refresh-токен при выходе

После выхода старый refresh-токен оставался рабочим, и сессию
можно было продлить с другого устройства.

Refs: PROJ-123
```

## Что внутри

- Скилл `commit-message` — смотрит индекс, историю коммитов и имя ветки, выбирает тип и scope, пишет тему в прошедшем времени, тело объясняет «почему», а номер задачи из ветки уходит в футер `Refs:`. Предлагает разбить коммит, если в диффе несвязанные изменения.

Вызов: попросите «напиши сообщение коммита» или вызовите скилл по имени, можно с номером задачи: `/commit-message PROJ-123`.
